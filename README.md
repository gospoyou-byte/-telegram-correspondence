# Cherry Gram ♡

✈️ Виртуальный Telegram-мессенджер внутри SillyTavern

## Возможности

- 💬 Переписки с персонажами
- 😺 Стикеры и эмодзи
- ❤️ Реакции на сообщения
- ↩️ Ответы и редактирование
- 📢 Telegram-каналы с постами и комментариями
- 🌸 Истории
- 🖼 Генерация изображений (NovelAI, свой API, SD)
- 📎 Вложение фотографий
- 🤖 AI-ответы персонажей
- 👤 Профили
- ⚙️ Гибкие настройки
- 🔄 Синхронизация с ролевой игрой
- 📱 Перемещаемая кнопка

## Установка

1. Откройте SillyTavern
2. Перейдите в **Extensions** → **Install Extension**
3. Вставьте URL: `https://github.com/YOUR_USERNAME/Cherry-Gram`
4. Нажмите **Install**
5. Перезагрузите страницу

## Использование

Нажмите кнопку ✈️ в углу экрана. Кнопку можно перетаскивать.
